# Science Adventure Media Order

A fan-made guide for the SciAdv universe media as a "first project" to practice CSS and Flexbox without guidelines or tips from my courses.

I tried going for a minimalist style, but it ended up looking a bit busy because of the notes under the image, also I am not the best at designing layouts.

## Made With

- HTML5
- Semantic tags.
- CSS (Flexbox for layout).
- Caffeine and no sleep.
